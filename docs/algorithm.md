# 龙区分与单局称号：算法说明

这份文档一步一步讲清楚分数是怎么算出来的，并附一个从头算到尾的真实例子。为什么这样设计、回测效果如何，见 [rating-design.md](rating-design.md)。

文中的数字都来自当前的模型文件 `src/dragonModel.json`。重新拟合后数字会变，公式不变。

## 0. 两套东西

| | 回答什么 | 看不看 ELO | 在哪显示 |
|---|---|---|---|
| **龙区分**（玩家，1~10） | 这个人在他的分段、他的角色构成里算不算强 | 看：和同 ELO、同角色构成的玩家比 | 玩家查询里的龙区分面板 |
| **龙 / 区 / 泯**（单局） | 这一局他打得怎么样（同上的比法） | 看 | 上一局、对局档案里名字前的大字 |
| **称号**（单局） | 这一局他对战局实际起了多大作用 | **不看**：高分带低分，功劳就是功劳 | 名字后面的标签，每人一个 |

## 1. 数据

| 接口 | 用来做什么 | 关键字段 |
|---|---|---|
| `/api/players/matches`（最近 20 场） | 玩家龙区分 | 每场全部玩家的赛前/赛后 ELO、摧毁分、损失分、队伍、时长 |
| `/api/analysis/player` | 玩家的生涯角色 | 各兵种类别的花费、最常用的 15 个单位 |
| `/api/match`（单局） | 龙/区/泯、称号 | 上面这些，加上每个单位的出生/阵亡时间、伤害、击杀、补给流向、误伤、游戏的逃兵标记 |

「摧毁分」「损失分」是按单位价值算的分，不是击杀数。接口是 protobuf 转 JSON，值为 0 的字段会被省略（例如缺 `TeamId` 就是 A 队）。

## 2. 角色

单位库里每个单位都有类别和用途，据此分成 7 类：

| 角色 | 包含 |
|---|---|
| 装甲 | 所有载具（坦克、步战车、装甲运兵车、反坦克车） |
| 步兵 | 步兵（单兵防空除外） |
| 侦察 | 侦察类单位，包括无人机 |
| 炮兵 | 支援类里的火炮、火箭炮、迫击炮、战术导弹 |
| 防空 | 支援类里的防空车/防空导弹，加上单兵防空 |
| 直升机 | 武装直升机、侦察直升机 |
| 固定翼 | 攻击机、轰炸机、战斗机 |

卡车、运输直升机、运输机不计入任何角色。

- **单局角色**：用这一局实际出的单位，按价格加权算占比。例如这局出了 30% 装甲、24% 防空……
- **生涯角色**（用于玩家龙区分）：取生涯各类别的花费，同一类别里再按最常用的单位拆分。比如「支援」拆成炮兵和防空，常用单位里没覆盖到的部分，按全体玩家的平均拆分（支援 → 炮兵 35%、防空 44%、其余是卡车），平均拆分的分量相当于该类别花费的 30%。
- 没有数据时，按全体平均构成算：装甲 23%、步兵 18%、侦察 14%、炮兵 9%、防空 14%、直升机 5%、固定翼 19%。

每个人都是混编，所以角色是一组比例，不是单一标签。

## 3. 每场的三个量

以下 D = 本人摧毁分，L = 本人损失分。

| 量 | 公式 | 意思 |
|---|---|---|
| K/D | `x_kd = log2((D + 200) / (L + 200))` | 交换比，取对数是为了让 ×2 和 ÷2 对称；加 200 防止 0 分时算出无穷大 |
| 摧毁贡献 | `x_con = log2((D + 200) / (本队在线队员人均摧毁 + 200))` | 你在队里打掉的份额，和对局时长、投降无关 |
| 胜负残差 | `S − E`（赢了 S = 1，输了 S = 0） | 比 ELO 预期多赢了多少 |

- **预期胜率**：`E = 1 / (1 + 10^((对方 − 本方) / 400))`。本方、对方各取**在线队员**的赛前平均 ELO，每缺 1 个人，该队按弱 **500 分**算（中途离开的按缺席时长折算）。500 和 400 这两个数都是从 5567 局真实对局里拟合出来的。
- **占点**：占点和地图、选位强相关，**不计分**。

## 4. 标准化：和谁比

同样是 K/D 1.0，对炮兵是亏，对装甲是赚。所以每个量先换算成「同类玩家里的位置」：

```
预期值 μ = Σ 角色占比 × 该角色的均值  +  0.44 × (本人 ELO − 这局平均 ELO) / 400  +  (几乎为 0) × (本人 ELO − 2100) / 400
离散度 σ = √(Σ 角色占比 × 该角色的方差)
标准分 z = (x − μ) / σ
百分位   = z 在全体数据里排第几（查分布表）
```

各角色 K/D 的均值（单局口径，`2^均值` 就是该角色的典型 K/D）：

| 装甲 | 步兵 | 侦察 | 炮兵 | 防空 | 直升机 | 固定翼 |
|---|---|---|---|---|---|---|
| −0.77（0.59） | −0.69（0.62） | −0.08（0.95） | 1.14（2.2） | 1.31（2.5） | −1.26（0.42） | 0.58（1.5） |

- 防空和炮兵的典型 K/D 在 2 以上。所以后排打出 1.0 已经排在后 20% 左右，而装甲打出 1.0 能进前 20%。
- **分差项**：一个人比同局平均高 400 分时，预期 K/D 要乘 1.36（2^0.44）。被抓进高分局的人会得到相应照顾，在低分局炸鱼的人则要打得更好才算龙。绝对 ELO 本身几乎没有影响。
- 这些均值和离散度用岭回归估出（「共同均值 + 各角色偏离」，偏离量往 0 收缩），收缩强度按玩家分折的交叉验证来选。单局和生涯各有一套。

## 5. 单场分与龙 / 区 / 泯

```
单场综合分 c = 0.5 × z_kd + 0.5 × z_con + 0.5 × (S − E) / 0.456
单场分       = 1 + 9 × (c 在全体单场里的百分位)
```

- 0.456 是胜负残差的标准差，除以它是为了把胜负项和另外两项换算到同一尺度。
- K/D 和摧毁贡献各占一半、胜负项系数 0.5，都是用回测选出来的：用过去 20 场的分数，预测之后「实际胜负 − ELO 预期」，哪组预测得最准就用哪组。
- **单场分 ≥ 8.2 标「龙」**（前 20%），**≤ 2.8 标「区」**（后 20%），其余标「泯」。

### 例子：8803400 这局的 ATG（赢）

| 步骤 | 数值 |
|---|---|
| 本局角色 | 防空 24%、装甲 21%、步兵 17%、固定翼 14%、侦察 14%、炮兵 11% |
| 摧毁 / 损失 | 6405 / 3060（K/D 2.09），摧毁是本队在线人均的 1.38 倍 |
| ELO | 本人 2317，本队 2320，对方 2147，全场平均 2234 → 预期胜率 E = 0.730 |
| K/D | x = log2(6605 / 3260) = 1.019；μ = 0.310，σ = 0.754 → z = 0.94（第 86 百分位） |
| 摧毁贡献 | x = 0.453；μ = −0.028，σ = 0.467 → z = 1.03（第 87 百分位） |
| 胜负 | (1 − 0.730) / 0.456 = 0.592 |
| 综合 | c = 0.5 × 0.94 + 0.5 × 1.03 + 0.5 × 0.592 = 1.28 → 第 91 百分位 |
| 结果 | 单场分 1 + 9 × 0.909 = **9.2 → 龙** |

## 6. 玩家龙区分：卡尔曼滤波

把一个人的「真实水平」看作一个随时间缓慢变化的值，每一场的综合分 c 都是对它的一次带噪声的观测。从最早的一场往最近的一场依次更新：

```
开始：估计 m = 0（普通），不确定度 P = P0 = 0.1425
每一场：
  P ← P + q                         （水平可能漂移，q = 0.0012）
  R = r ÷ min(1, max(0.3, 时长 / 16 分钟))   （单场噪声 r = 1.045；短局噪声更大）
  K = P / (P + R)                   （这一场占多少分量）
  m ← m + K × (c − m)
  P ← P × (1 − K)
```

- P0、q、r、16 分钟这四个数，都是用 180 名玩家的对局序列按「一步预测似然」拟合出来的。
- r / P0 ≈ 7.3，相当于分数先天带着「7 场普通表现」往中间拉。20 场也只能大致定位一个人，所以面板上会显示可能范围。
- 越近的对局分量越大；一局 5 分钟的对局分量只有正常对局的 1/4～1/3。

**最终分数** = m 在全体玩家里的百分位（按对局池各 ELO 档的人数加权还原）→ `1 + 9 × 百分位`。所以 5.5 就是中位数。**可能范围** = m ± √P 对应的分数。

| 分数（百分位） | 档位 |
|---|---|
| ≥ 9.1（前 10%） | 🐉 真龙 |
| ≥ 7.3（前 30%） | 有龙样 |
| ≥ 3.7 | 泯然众人 |
| ≥ 1.9（后 30%） | 有点区 |
| < 1.9（后 10%） | 纯区 |

**例子**（ATG 最近 20 场）：每场的分量从最早一局的 0.12 逐渐降到 0.05，其中一局 5 分钟的对局只占 0.023。最后 m = 0.282，√P = 0.227，排在第 83 百分位 → **8.5，有龙样，可能范围 6.0～9.8**。

面板上的三个分项（K/D、摧毁贡献、胜负预期）是 20 场各自百分位的平均。「原因」一栏挑出偏离普通最明显的几项，例如「胜率 80%，高于 ELO 预期的 63%」「K/D 中位数超过同角色、同分段 62% 的玩家」。

## 7. 掉线 / 挂机

符合以下任一条件，就判为掉线或挂机：

1. 游戏标记为逃兵（`Deserter`），而且在对局进行到 85% 之前离开（离开时间按最后一次出兵估算）；
2. 整局摧毁分和损失分都是 0；
3. 最后一次出兵早于对局进行到 40% 的时刻，而且摧毁不到本队人均的 15%。

判定之后的影响：

- 掉线的人不计入本队人均（其他人的贡献不会因此虚高）。
- 缺人的一方，预期胜率按「每缺 1 人弱 500 分 × 缺席比例」重算（以少打多输了，几乎不扣分）。
- 掉线的人自己不享受这个减免。
- 「最近对局」接口没有逃兵标记和单位数据，所以玩家龙区分只能用第 2 条判断。

## 8. 单局称号

只看这一局的实际作用，**不看 ELO、不看角色、不看占点**。

**净交换 = 摧毁分 − 损失分**

### 功劳与背锅（每局都会评）

| 称号 | 条件 |
|---|---|
| 大腿 | 赢方净交换最高（不算掉线的人） |
| 背锅侠 | 输方净交换最低；输方有人掉线时，锅直接归掉线的人（他显示掉线狗） |
| 掉线狗 | 第 7 节的掉线/挂机判定 |
| 带不动 | 输了，但净交换是全场第一 |
| 躺赢狗 | 赢了，但净交换为负，而且在全场（不算掉线的人）垫底 |
| 孤勇者 | 本队有人掉线，他是本队净交换第一，而且全场前 3 |

### 突出表现（每种称号一局只给最突出的一个人）

门槛是按真实数据校准的：取 270 局里「每局最突出的那个人」的数值分布，让每种称号只在约 3%～8% 的对局里出现。表里是当前模型的门槛。除注明「全部人」的几项外，只在「没掉线、对局 ≥ 8 分钟」的人里评。

| 称号 | 条件 | 门槛 |
|---|---|---|
| 收割机 | 摧毁分占全场比例最高 | ≥ 20% |
| 保活能手 | 摧毁 ≥ 队均，损失占本队比例最低 | ≤ 8.5% |
| 举重冠军 | K/D 在 0.75～1.33，击杀数和阵亡数占全场比例都最高 | 两项都 ≥ 14.5% |
| 开送 | K/D < 0.5，损失分占全场比例最高 | ≥ 18.5% |
| 刮痧师傅 | 摧毁 < 队均 0.8 倍，伤害占全场比例最高 | ≥ 12.9% |
| 人头狗 | 摧毁 ≥ 队均，每点伤害换来的摧毁分最多 | ≥ 10.3 |
| 落地成盒 | 阵亡 ≥ 10 个单位，阵亡单位存活时间中位数最短 | ≤ 79 秒 |
| 蹲逼 | 对局 ≥ 10 分钟、摧毁 ≤ 队均一半，损失占本队比例最低 | ≤ 11.4% |
| 地产大亨 | 占 ≥ 3 个点，占点占本队比例最高 | ≥ 51% |
| 拆迁办 | 拆掉的建筑最多 | ≥ 41 栋 |
| 运输大队长 | 补给被敌人缴获最多（全部人） | ≥ 14190 |
| 舔舐者 | 缴获敌方补给最多 | ≥ 13746 |
| 奶妈 | 队友用掉他的补给最多 | ≥ 16426 |
| 干饭王 | 用掉队友的补给最多 | ≥ 16551 |
| 空投快递员 | 空投的补给最多 | ≥ 16000 |
| 七天无理由退货 | 退款占出兵价值的比例最高 | ≥ 59% |
| 败家子 | 摧毁 < 队均 0.7 倍，出兵花费占全场比例最高 | ≥ 12% |
| 大义灭亲 | 误伤摧毁的友军价值最高（全部人） | ≥ 320 |
| 被背刺 | 被友军误伤损失最多（全部人） | ≥ 350 |
| 曼巴out | 损失的直升机/飞机价值最高 | ≥ 2515 |
| 大炮兵主义 | 炮兵占出兵 ≥ 30%，摧毁分占全场比例最高 | ≥ 12% |

### 每人只显示一个：比谁更罕见

一个人同时符合多个称号时，估计「一个随机玩家在一局里拿到这个称号，而且至少这么夸张」的概率，**概率最小的胜出**：

- 突出表现：真实数据里「每局最突出者至少这么夸张」的对局比例 ÷ 10 人；
- 大腿、背锅侠、带不动、躺赢狗、孤勇者：它们的实际出现频率 ÷ 10 人。大腿每局都有，约 1/10；带不动约 1.9%；
- 掉线狗永远优先。

所以大腿如果同时是收割机，会显示收割机，因为后者更罕见。大腿和背锅是谁，仍然写在复盘摘要那一行。

**例子**（8803400）：

- 赢方 ATG 净交换 6405 − 3060 = **+3345**，全队最高 → 大腿。
- 输方 Onscreen 3990 − 6635 = **−2645**，全队最低 → 背锅侠。
- Dont 拆了 56 栋建筑，超过 41 的门槛 → 拆迁办。

## 9. 参数从哪来

| 参数 | 来源 |
|---|---|
| ELO 尺度 400、缺人 500 分 | 5567 局真实对局，按预测胜负的 log loss 最小来选 |
| 单位 → 角色、类别拆分比例 | BATrace 单位库 + 270 局单位级数据 |
| 各角色的均值和离散度、ELO 与分差系数 | 岭回归（单局 2597 行、生涯 6571 行），收缩强度用按玩家分折的交叉验证选 |
| 百分位表 | 全体单场和全体玩家的实际分布 |
| 分项权重、胜负项系数 | 回测（159 人，预测之后的「实际胜负 − ELO 预期」） |
| 卡尔曼 P0 / q / r / 短局时长 | 一步预测似然 |
| 龙区分分档（10/30/70/90%）、龙区标记（20/80%） | 设计约定（按百分位定，所以两端一定够得着） |
| 称号门槛、罕见程度 | 270 局里每局最突出者的分布 |
| 不计占点、掉线判定的 85% / 40% / 15% | 设计约定 |

## 10. 局限

- BATrace 没有「谁打死了谁」的记录，看不出「一个人打两个」这类局部情况；也没有投降投票记录，不知道是谁发起的投降。
- 玩家龙区分的角色用的是生涯花费，而不是每一局的实际出兵（那样每查一个人要多请求 20 次）；也没法按阵营分开统计。
- 样本是 180 人、270 局，有些参数还不够稳，见 [rating-design.md](rating-design.md#后续)。
